# Desafio calculadora financeira

inspirado nos desafios do curso em video, resolvi fazer esse desafio como um teste do meu conhecimento em PHP

o desafio consisite em criar uma calculadora que pega o seu dinheiro recebido (via input) e retorna aonde voce vai colocar parte do valor recebido,
por exemplo: 50%/30%/20% (50 para contas de casa, como agua, luz e aluguel, 30% para compras como compras de supermercado, aquele restuante no domingo, etc e 10% para reserva de ermegencia)

as opções de regras financeiras são:
 - 70/30
 - 70/20/10
 - 50/30/20 ou
 - 60/20/10/10 (esses 10 seriam para aposentadoria (ou doações))
